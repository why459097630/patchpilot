# PatchPilot

**AI-agent-like coding efficiency, without local agent setup.**

PatchPilot is a desktop application that helps developers safely apply multi-file code changes generated by web-based AI assistants.

Instead of manually searching for code blocks, copying replacements, and editing files one by one, PatchPilot turns AI-generated changes into a structured and controlled PATCH workflow.

## What is PatchPilot?

PatchPilot connects web-based AI coding with your local project through a simple workflow:

1. Select and package your project.
2. Send the project ZIP and generated instructions to an AI assistant.
3. Paste the AI-generated PATCH into PatchPilot.
4. Review, match, and apply the selected changes.
5. Verify the result with automatic backups, build checks, history, and rollback.

AI generates the code changes. PatchPilot precisely matches, applies, protects, and verifies them.

## How It Works

### 1. Prepare your project

Select a project folder, review included files, exclude unnecessary content, and create a project ZIP for AI analysis.

Key capabilities:

- Project file selection
- Smart file exclusion
- Project ZIP generation
- Dedicated AI request instructions

### 2. Generate the PATCH with AI

Send the generated instructions and project ZIP to an AI assistant that supports project file analysis.

The AI reviews the real project structure and returns structured PATCH instructions containing the required code changes.

### 3. Review and apply safely

Paste the generated PATCH into PatchPilot.

PatchPilot will:

- Parse multi-file changes
- Match original code exactly
- Show matched and unmatched replacements
- Let you select which changes to apply
- Create an automatic backup
- Apply selected replacements
- Run the configured project build
- Record the operation in patch history
- Provide rollback when needed

## Safety and Control

PatchPilot is designed to keep AI-generated code changes controlled and reversible.

### Exact matching

Only changes whose original code can be matched against the current project are eligible to be applied.

### Review before modification

Parsed changes remain visible and selectable before PatchPilot writes to project files.

### Automatic protection

Before applying changes, PatchPilot creates backups so the previous project state remains recoverable.

### Build verification

After applying a PATCH, PatchPilot can run the project build and report whether the modified project passes verification.

### History and rollback

Applied changes are recorded in history and can be rolled back when necessary.
