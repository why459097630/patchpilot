# PatchPilot

**AI-agent-like coding efficiency, without local agent setup.**

PatchPilot is a Windows desktop application that helps developers safely apply multi-file code changes generated by web-based AI assistants.

Instead of manually searching for code blocks, copying replacements, and editing files one by one, PatchPilot turns AI-generated changes into a structured, reviewable, and reversible PATCH workflow.

## What is PatchPilot?

PatchPilot connects web-based AI coding with your local project through a controlled workflow:

1. Select and package your project.
2. Send the project ZIP and generated instructions to an AI assistant.
3. Paste the AI-generated PATCH into PatchPilot.
4. Review matched and unmatched changes.
5. Select the changes you want to apply.
6. Apply the selected changes with automatic backups.
7. Verify the result with a build check.
8. Use history and rollback when needed.

The AI assistant generates the proposed code changes. PatchPilot matches, applies, backs up, verifies, records, and helps reverse those changes.

## Safety and Control

PatchPilot is designed to keep AI-generated code changes controlled, reviewable, and reversible.

### Exact matching

PatchPilot checks each PATCH change against the current project files.

When the original code cannot be matched exactly, the change is identified instead of being silently applied.

### Review before modification

Parsed changes remain visible and selectable before PatchPilot writes to the project.

You decide which changes are applied.

### Automatic backups

PatchPilot creates backups before applying selected changes so the previous project state remains recoverable.

### Build verification

After applying a PATCH, PatchPilot can run the configured project build and report whether the modified project passes verification.

When a build fails, PatchPilot can provide an error summary and build logs for further analysis.

### History and rollback

Applied changes are recorded in history. Backups, snapshots, and rollback tools help restore an earlier project state when needed.

    ↓

Web-based AI assistant
    ↓

## Frequently Asked Questions

### What is PatchPilot?

PatchPilot helps developers safely apply AI-generated code changes. AI creates the proposed changes, while PatchPilot precisely matches, reviews, applies, backs up, verifies, records, and helps reverse them.

### Does PatchPilot generate code?

No. Your AI assistant generates the proposed code changes. PatchPilot prepares the workflow and applies the resulting structured PATCH to your local project.

### Does PatchPilot replace ChatGPT, Claude, Cursor, or other AI coding tools?

No. PatchPilot works alongside AI coding assistants. It provides a structured and controlled way to transfer AI-generated changes into your local project.

### Does PatchPilot require an AI API key?

No. PatchPilot does not require a separate AI API key.

### Does PatchPilot require a local AI model?

No. You can use a supported web-based AI assistant to analyze your project and generate the PATCH.

### Does PatchPilot upload my project automatically?

PatchPilot prepares a project ZIP locally. You decide which AI service receives the ZIP and generated instructions.

### Can every AI service read project ZIP files?

No. The AI service you use must support reading or analyzing the project files you provide.

### Is my project modified automatically?

No changes are applied until the PATCH has been parsed, matched, reviewed, selected, and explicitly applied.

### What happens when the original code cannot be matched?

PatchPilot identifies the unmatched change instead of silently applying it as an exact replacement.

### Does PatchPilot create backups?

Yes. PatchPilot creates backups before applying selected changes.

### Can PatchPilot verify the modified project?

Yes. PatchPilot can run the configured project build and report the result.

### Can changes be rolled back?

PatchPilot records applied changes in history and provides backups, snapshots, and rollback support.

### Does PatchPilot increase AI usage costs?

PatchPilot is designed to reduce repetitive context usage by using a ZIP + PATCH workflow instead of repeatedly synchronizing the entire project with a local AI agent.
