# ChangeLatch

**AI-agent-like coding efficiency, without local agent setup.**

ChangeLatch is a Windows desktop application that helps developers safely apply multi-file code changes generated by web-based AI assistants.

Instead of manually locating code blocks, copying replacements, and editing files one by one, ChangeLatch turns AI-generated changes into a structured, reviewable, and reversible PATCH workflow.

## What ChangeLatch Does

ChangeLatch provides a controlled local application layer between web-based AI and your project:

1. Select a local project and review the files included for analysis.
2. Generate a project ZIP and dedicated AI instructions.
3. Send the ZIP and instructions to an AI service capable of analyzing project files.
4. Paste the returned structured PATCH into ChangeLatch.
5. Review matched and unmatched changes.
6. Select the changes you want to apply.
7. Apply them with automatic backups.
8. Run the configured build and review the result.
9. Use history, snapshots, and rollback when needed.

The AI assistant proposes the code changes. ChangeLatch matches, reviews, applies, backs up, verifies, records, and helps reverse those changes.

## How the Workflow Fits Together

```text
Local project
    ↓
Project ZIP + generated instructions
    ↓
Web-based AI assistant
    ↓
Structured PATCH
    ↓
ChangeLatch review + exact matching
    ↓
Backup → Apply → Build check → History
```

The AI service you use must be able to read or analyze the project files you provide.

## Safety and Control

### Exact matching

Each replacement is checked against the current project before it can be applied.

### Explicit selection

You choose which parsed changes are included in the operation.

### Automatic backups

A backup is created before selected changes modify the project.

### Build verification

The configured project build can run immediately after the PATCH is applied.

### History and rollback

Applied operations are recorded so previous states can be reviewed and restored when supported by the available history.

### Local project handling

ChangeLatch prepares and processes project files locally. It does not automatically upload your project to an AI service. You decide which external AI service receives the generated ZIP and instructions.

## Frequently Asked Questions

### What is ChangeLatch?

ChangeLatch helps developers safely apply AI-generated code changes through a structured ZIP-to-PATCH workflow with exact matching, review, backups, build verification, history, and rollback support.

### Does ChangeLatch generate code?

No. Your AI assistant generates the proposed changes. ChangeLatch prepares the project package and instructions, then processes the structured PATCH returned by the AI.

### Does ChangeLatch replace ChatGPT, Claude, Cursor, or other AI coding tools?

No. ChangeLatch works alongside AI coding tools. It provides the controlled local application layer for AI-generated changes.

### Does ChangeLatch require an AI API key?

No. ChangeLatch does not require a separate AI API key.

### Does ChangeLatch require a local AI model?

No. You can use a web-based AI service capable of analyzing the project files you provide.

### Does ChangeLatch automatically upload my project?

No. ChangeLatch prepares the project ZIP locally. You decide where and whether to upload it.

### Can every AI service analyze the project ZIP?

No. The AI service must support reading or analyzing the project files you provide.

### Are changes applied automatically?

No. The PATCH must be imported, matched, reviewed, selected, and explicitly applied.

### What happens when the original code cannot be matched?

The change is identified as unmatched instead of being silently applied as an exact replacement.

### Does ChangeLatch create backups?

Yes. ChangeLatch creates backups before applying selected changes.

### Can ChangeLatch verify the modified project?

Yes. ChangeLatch can run the configured project build and report the result.

### Can changes be rolled back?

ChangeLatch records applied operations and provides backups, snapshots, history, and rollback support.

### Is the application source code included in this repository?

No. This repository is the official documentation, release, download, and issue-tracking repository for ChangeLatch.
